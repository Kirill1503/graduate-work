# Graduate Work

## Описание проекта

Этот проект является итоговой дипломной работой для курса Java Developer для SkyPro и представляет собой реализацию backend для сервиса, предоставляющего возможность его пользователям
создавать и редактировать объявления о продаже различных продуктов и услуг. Так же в сервисе присутствует реализация
системы комментариев к объявлениям, что облегчает коммуникацию между пользователями.

## Используемые библиотеки и инструменты

В проекте используются следующие библиотеки и инструменты:

- **Spring Boot**: Основной фреймворк для разработки Web-приложения на Java.
- **PostgreSQL**: Система управления базами данных, используемая для хранения данных приложения.
- **Liquibase**: Инструмент для управления версиями базы данных.
- **Spring Data JPA**: Модуль, упрощающий работу с базами данных с использованием JPA (Java Persistence API).
- **Spring Security**: Библиотека обеспечивающая безопасность приложения и предоставляющая инструменты для управления аутентификацией и авторизацией пользователей.
- **Swagger**: Инструмент для документирования API, позволяющий легко тестировать и взаимодействовать с endpoint-ами вашего приложения.
- **Maven**: Система используемая для управления зависимостями и сборки проекта.

## Примеры сценариев использования

### 1. Регистрация пользователя

**"http://localhost:8080/register"**: `POST`

**Тело запроса**:

{
  "username": "string",
  "password": "string",
  "firstName": "string",
  "lastName": "string",
  "phone": "string",
  "role": "USER"
}

### 2. Вход в учётную запись пользователя

**"http://localhost:8080/login"**: `POST`

**Тело запроса**:

{
  "username": "string",
  "password": "string"
}
